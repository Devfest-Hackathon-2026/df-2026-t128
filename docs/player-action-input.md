# 発言と行動の入力

発言、行動、その両方を同じ欄に500文字まで入力できます。画面からは本文とともに `kind: auto` を送り、本人にかけた言葉と、その場でした行動を区別して応答と振り返りに使います。

入力欄の「例：」には、直前のやり取りに応じた発言例が表示されます。空欄でTabを押すか、タッチ画面で入力欄の「↳」をタップすると下書きに入り、自由に編集してから送信できます。欄の上の候補を選ぶと、例文とは別の発言や行動が入ります。3往復後からは「練習を終えて振り返る」が候補に加わります。これを選ぶとメッセージを送らずに振り返りへ進みます。

最初の2案は、各場所でプレイヤーが目にした状況に合わせます。人物が応じた後は、Geminiがその返事と会話履歴から作った2案を使います。本人の返事を待つか、善意で少し先回りするかなど、選んでみて初めて違いに気づける候補にします。画面に良否は表示しません。候補を見ただけでは、履歴にも振り返りにも記録されません。
