# 声かけ練習の参照資料と設計への反映

確認日: 2026年11月7日

## 一次資料

- [神戸市「認知症の人との接し方」](https://www.city.kobe.lg.jp/a39067/kenko/fukushi/carenet/ninchisyou/ninchisyounohitotonokakawarikata.html)（ページ更新: 2026年10月21日）。対応の3原則と7つのポイントを確認。
- [全国キャラバン・メイト連絡協議会「復習しよう！サポーター講座」](https://www.caravanmate.com/study/)。標準教材に基づく同原則と、状況ごとに唯一の正解を決められないという説明を確認。教材本文・問題の転載は行わず、独自の架空場面を作成。
- [厚生労働省「認知症サポーター」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000089508.html)。偏見を持たず、身近な地域でできる範囲の手助けをするという位置づけを確認。

## 参照した考え方

3原則は「驚かせない」「急がせない」「自尊心を傷つけない」。7ポイントは、まずその場の様子を見ること、自分も焦らないこと、声かけは一人から始めること、見える位置から話すこと、目線と口調に配慮すること、穏やかで明瞭に伝えること、返答を待って話を聞くこと、と整理した。詳しい説明は上記一次資料を参照。

## KindSignalでの扱い

- 練習の対象は、困っている人の希望を聞く声かけ。外見や会話から認知症かどうかを判断しない。
- 登場人物・店舗・施設・場面は架空。年齢や診断と困りごとを結びつけない。
- 最初の行動選択に対する振り返りと、その後の自由会話に対する振り返りを分ける。得点、正解率、人物の評価は設けない。
- 拒否を尊重して終了する経路は本プロダクトの設計方針。援助を受け入れてもらうことを達成条件にしない。見守りを人物の追跡や監視として実装しない。
- 店内の探し物、バス停での行き先確認、駅前での援助辞退の3場面を使用する。行動・会話は学習用に独自作成した例であり、一次資料の事例の転載ではない。
- デモモードは固定応答を表示する。自由入力の意味を理解した応答・評価ではないことを画面で明示する。Geminiを使う場合も、実際の発言に根拠がない行動や成果を振り返りに追加しない。

本プロトタイプは公的機関の認定教材や認知症サポーター養成講座ではない。研修修了・資格付与・対応力の向上を保証しない。公開前に、認知症サポーター養成担当者などによる内容確認を実施することを推奨する。
