# 声が届く前の状況と、会話に重なる記憶

駅の山本さんの冒頭は、案内板を見ている本人の独り言。まだ気づいていないことをプレイヤーにも表示する。声だけなら声の主を確かめる間がある。視界に入って気づくのを待った後なら、同じ挨拶でも状況が違う。スーパーで自分から頼んできた田中さんのように、既にやり取りが始まっている場合は、挨拶を失点にしない。介助の手順を入力させる採点には使わない。

佐藤さんには高校の図書室で友達と本を回し読みした記憶を、山本さんには青いバスで通学した記憶を設定した。前者は名前を思い出せなくてもその友達のことを語れる例、後者は目の前の案内や帰宅の話と昔の通学が一時的に重なる例。これらは架空の個人の設定で、病期や認知症の人に共通する反応を示すものではない。

設計の参考：[厚生労働省掲載の接遇の手引き](https://www.mhlw.go.jp/content/12600000/001447275.pdf)、Alzheimer’s Society の[記憶と時間の感覚](https://dementiaconnect.alzheimers.org.uk/about-dementia/stages-and-symptoms/dementia-symptoms/time-shifting)・[言葉や名前の想起](https://www.alzheimers.org.uk/about-dementia/types-dementia/alzheimers-disease-symptoms)。
