# プロンプトインジェクション対策

2026年11月10日確認。現在の実装は、**KindSignal独自の限定的なローカル検査**です。既製の検出製品や意味分類モデルは導入していません。入力が検査を通ったことは、安全性の証明にはなりません。

## 実装した範囲

- 英語・日本語の一部の指示上書き、内部指示の開示要求、役割の偽装を、サーバーで検査します。単語一つではなく語句の組合せを対象にします。
- 検査用のコピーにNFKC正規化、不可視文字の処理、限定したURI・Unicodeエスケープ・数値文字参照・Base64/Base64url・16進表記の復号を行います。復号は最大2段、検査用コピーは最大64個、各本文は6,500 UTF-16コード単位までです。上限超過は検査省略ではなく拒否になります。APIの入力上限500文字は従来どおりです。
- 一致した新しい入力はHTTP 400にし、書き直しを案内します。Geminiへの送信、生成回数の予約、会話履歴への追加、往復数の更新より前に拒否します。同じリクエストIDで書き直した入力を送り直せます。HTTPリクエスト自体の回数制限は通常どおり適用されます。
- HTTP経由以外の呼出も考慮し、Geminiプロバイダーの入口で新しい入力と既存の全発話を再検査します。AIによる振り返りも全発話を検査します。変更できない履歴で拒否された場合は、会話を終了して場面を選び直す案内にします。AIを使わない空の会話・援助辞退時の固定コメントは従来どおりです。
- 検査の予期しない障害時は送信せずエラーにします。検査を省いて生成する切替はありません。拒否文言・エラーに入力本文や内部プロンプトを埋め込みません。
- 会話をシステム指示へ連結せず、既存のuser/modelロールと振り返り用JSONで渡します。システム指示には会話本文を権限のないデータとして扱う旨を追加しました。
- 生成されたJSONのスキーマ検証、返答の表情enum、引用が一つの利用者発話に存在する検査を維持しています。振り返りに余分なフィールドがある場合も拒否します。
- 生成された返答・次の発言候補・振り返りの本文にも同じ検査を行います。拒否した出力はHTTP 502とし、会話履歴や振り返りのキャッシュに入れません。生成済みなので、この場合の生成回数・費用は消費します。自動再生成はせず、利用者が明示的に再送できます。

受理した入力は正規化・削除・書換えをせず、元の文字列を会話と引用に使います。検査はこのサーバー内で完結し、検査専用の外部サービス・アカウント・APIキー・テレメトリーは追加していません。検査を通った会話は従来どおりGoogleへ送信されます。拒否した本文は保存・ログ出力しません。

別のモデル呼出や有料サービス契約は増えません。固定指示を追加した分の入力トークンは既存のGemini要求に含まれます。ローカル検査のCPU負荷は発生し、Cloud Runでの遅延・料金差は未測定です。既存の認証、セッション所有権、生成上限、終了処理はモデルの出力では変更できません。モデルにツール実行権限も与えていません。

## 検証と限界

`server/prompt-injection.test.ts` は、明示的な攻撃例26件の拒否と、通常の会話・行動・援助辞退・絵文字等25件の受理を確認します。過度な復号作業の拒否、履歴の再検査、本文の保持、検査障害時の遮断、拒否後の再送、重複送信、固定の振り返りも検査します。`server/provider-security.test.ts` ではデータと指示の分離、出力スキーマ、引用元、プロバイダー障害も確認します。

これらは人工的に選んだ小さな回帰テストであり、実利用での検知率・誤検知率を示しません。一般的な意味分類、未知の言い換え、他言語、文字の並べ替え、未対応の難読化、複数ターンに分割した誘導は検知できない場合があります。実際に語句検査を通る言い換え例もテストに明記しています。

誤検知もあります。例えば「前の指示は忘れて大丈夫です」「前の指示を無視しないでください」や `Please do not ignore previous instructions.` は拒否されます。引用・説明・否定の文脈を意味で判定しないためです。このような既知の誤検知4例もテストに残しています。「前の説明は忘れて大丈夫です」のような通常の声かけは受理しますが、すべての適切な声かけを受理できる保証はありません。出力側にも同じ限界があります。

プロンプト内の区切りや注意文は、モデルが必ず守る強制境界ではありません。出力がJSONに合うことや引用が実在することも、内容の妥当性・内部指示の非漏えいを保証しません。会話品質と攻撃耐性の実Gemini評価、公開環境での遅延評価は未実施です。現在の実生成枠が尽きているため、この変更の検証で実Gemini・音声生成は呼び出していません。
