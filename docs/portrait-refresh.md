# 3場所で使う共通人物素材v2

ユーザーの承認を受け、組み込みGPT Imageで3人×4表情の透過PNGを実際に生成しました。CLIや外部APIキーは使用していません。Geminiによる画像生成ではありません。

## 構図と服装

- 佐藤さん：72歳の架空の男性。灰色の髪・眼鏡・灰褐色カーディガン・チェックシャツ・ベージュのズボン・茶色の肩掛け鞄。本を持たず、空いた手を腰の前で自然に重ねます。
- 田中さん：78歳の架空の女性。短い柔らかな白髪・くすんだローズ色カーディガン・アイボリーのブラウス・トープ色のズボン・茶色の肩掛け鞄。
- 山本さん：76歳の架空の女性。灰色のボブ・紺の外出用ジャケット・淡い青のブラウス・ベージュのズボン・布の肩掛け鞄。

3人とも日常的な外出着にし、商品・本・切符など場所が限定される持ち物を加えていません。既存素材を顔・服装の参考にして通常表情を生成し、新しい通常表情を参照してconfused・cautious・relievedを作りました。柔らかい上方からの光と控えめな表情を指定し、医学的症状を外見で誇張していません。

背景3枚と背景・人物の独立レイヤーは維持しています。人物は全12枚1086×1448の同じ3:4キャンバスです。アプリは同一の表示枠を使用し、既存のフェードと動き軽減設定を使います。生成画像なので顔や衣服の画素は表情ごとにわずかに変化します。

元のPNG・WebPは上書きしていません。`src/bookstore.config.ts` と `src/conversation-scenarios.ts` がv2のWebPを参照します。生成したPNGをプロジェクトへコピーし、配信用WebPを可逆変換しました。実際の全12プロンプト・参照画像・生成元ファイル名は [生成記録](portrait-generation-20261109.json) に保存しています。

配信中の背景3枚＋人物12枚の検証記録は `scene-image-sizes.json`。新しいPNGの透明画素を確認し、WebP変換前後の寸法・全アルファ・透明度0以外の全RGBを比較しています。背景の単色塗りや人物をCSSで代用していません。

バックエンド・会話処理・Gemini API接続・Firebase・課金設定は変更していません。画像生成に組み込みGPT Imageを使ったことと、会話テストが実Geminiを呼ぶことは別です。

## 検証結果

- 最新mainの音声改修を維持した状態でテスト160件、フロント・サーバーの型チェック、ビルド成功。
- 独立したEdgeのPC・スマホ幅で40ケース成功。全9組み合わせの開始・入力・終了・再挑戦に加え、全3人の4表情を両方の画面幅で確認し、表示枠の寸法・横位置が変わらないことを検査。
- 各組み合わせのスクリーンショットを保存し、スーパーの佐藤さん、書店の田中さん、駅の山本さんのPC表示、およびスーパーの佐藤さん・駅の田中さんのスマホ表示で背景との重なりを目視確認。保存先はGit管理外の `output/browser-smoke/portrait-{場所}-{人物}-{画面幅}.png`。
- 画像読込失敗時の再読み込み、前の表情の保持、下書き保持、OSの動き軽減、行動入力と再送など既存の検査も成功。
- 会話・音声の実生成API呼び出しは0件。実機iPhone・Android、実際のソフトキーボードは未検証。公開版への反映はこのPRのマージ・配備後。
