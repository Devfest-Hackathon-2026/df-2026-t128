# KindSignalの画面設計

認知症のある人との会話を練習する。街で相手に会い、話を聞き、次の行動を選ぶ体験を軸にする。開始・再挑戦などのボタンは「場所を選ぶ」「同じ相手でもう一度」のように、押した先の行動を書く。

| 役割 | 使う場面 |
| --- | --- |
| 深緑の背景 | トップ、場所選択、会話の舞台、振り返りの外枠。画面をまたいで維持する。 |
| 字幕 | 人物写真とともに、話者名と台詞を表示する。暗い半透明の地に明るい文字。狭い画面では写真直下に置いて顔を隠さない。 |
| 淡い紙色の面 | 会話を読んで振り返るとき。会話中は半透明の字幕面に淡い入力欄を重ねる。 |
| 金色 | 暗い背景の上で話者名やキーボードのフォーカスを見つけるために使う。選択の正解や点数を示さない。 |
| 操作 | 一番進んでほしい操作に塗りのボタンを使う。戻る・音量・全画面など繰り返す操作の記号は画面間で変えない。 |

共通の配色・見出し・画面余白は `src/practice-design.css` に定義する。チェック時はトップ→場所→会話→振り返りを通し、スマホで人物と操作が重ならないこと、キーボードでも現在の操作が分かることを確認する。

PC・スマホとも人物→発言→自分の選択・入力の順に縦に並べる。横長画面でも回答欄を字幕の右上に置かない。新しい返事が画面の外なら、字幕までスクロールしてから読めるようにする。

会話中は人物・背景を一枚の舞台として表示し、下部の半透明面には台詞とその場の選択肢または入力だけを置く。履歴・終了・振り返り・再生・設定は上部バーから操作する。
