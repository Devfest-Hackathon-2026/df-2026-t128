# KindSignal — OIF Team B

[公開版で体験する](https://kindsignal-api-279857506070.asia-northeast1.run.app/)

日常で困っている人を見かけたとき、どう声をかけますか。スーパー・書店・駅を舞台に、架空の人物と自分の言葉で会話し、声のかけ方と会話の終え方を振り返る成人向けの練習です。ログインは不要です。

1. トップで「場所を選ぶ」を押し、話しかける場所を選びます。人物の最初の言葉を読んで、ゲーム画面で自分の行動を選びます。
2. 言葉を入力すると、相手が表情と声で返事をします。音声はオフにもできます。
3. 会話を終えると、選んだ行動と自分の声かけを振り返れます。援助を断られたときは、再び勧めずその場で終えることもできます。

## 実行方法

Node.js 24 と npm を用意し、リポジトリのルートで以下を実行してください。

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5183 を開きます。ローカルの既定はキー不要の定型応答デモです。実際の生成音声と会話は上の公開版で試せます。

## 構成と制約

React と Express を Cloud Run で配信しています。本番では Vertex AI の Gemini が会話と参考コメントを生成し、Gemini-TTS が人物ごとの声を生成します。辞退を尊重して終えた場合は、固定ガイドを表示します。Firestore は生成試行回数の上限管理に使い、会話本文はサーバーのメモリに一時保持します。音声の生成失敗時も字幕で続けられます。個人情報は入力しないでください。

判断の練習を目的とし、診断や実在の人物の再現、対応の採点は行いません。[声かけの参照資料](docs/guidelines.md)と、各場面の素材説明（[スーパー](public/supermarket/ASSETS.md)・[書店](public/bookstore/ASSETS.md)・[駅](public/station/ASSETS.md)）を同梱しています。

確認コマンド：`npm test`、`npm run build`、`node scripts/deployment-smoke.mjs`。
