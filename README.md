# KindSignal — OIF Team B

[公開版で体験する](https://kindsignal-api-279857506070.asia-northeast1.run.app/)

認知症のある人との会話を練習します。相手の言葉から、何を望んでいるか考えてみてください。スーパー・書店・駅を舞台に、架空の人物と自分の言葉で会話し、声のかけ方と会話の終え方を振り返る成人向けの練習です。ログインは不要です。

スマートフォンではブラウザの「ホーム画面に追加」から起動できます。会話と音声にはインターネット接続が必要です。

1. トップで「場所を選ぶ」を押し、話しかける場所を選びます。目の前の様子が地の文で表示されます。まだ人物は話していません。
2. 自分から声をかけるか、行動を同じ欄に入力します。候補をタップして編集することもできます。送信して初めて相手が反応し、字幕・表情・音声で返します。音声はオフにもできます。
3. 会話は最大20往復で振り返りに進みます。途中でも振り返るか、振り返らずに中断するかを選べます。援助を断られたときは、再び勧めずその場で終えることもできます。

## 実行方法

Node.js 24 と npm を用意し、リポジトリのルートで以下を実行してください。

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5183 を開きます。ローカルの既定はキー不要の定型応答デモです。公開版ではGeminiの返答と音声を試せます。ページを再読み込みすると、その会話は終了します。

## 構成と制約

React と Express を Cloud Run で配信しています。本番では Vertex AI の Gemini が会話と参考コメントを生成し、Gemini-TTS が人物ごとの声を生成します。点数はつけず、発言や行動を振り返れます。アプリは累積利用回数や音声の累積文字数では停止しません。短時間の連続利用や同時生成は制限します。[入力・出力の検査](docs/prompt-injection-defense.md)では、一部の指示の上書きや内部指示の開示要求を拒否します。会話本文はサーバーのメモリに一時保持します。音声の生成失敗時も字幕で続けられます。個人情報は入力しないでください。

判断の練習を目的とし、診断や実在の人物の再現、対応の採点は行いません。[声かけの参照資料](docs/guidelines.md)と、各場面の素材説明（[スーパー](public/supermarket/ASSETS.md)・[書店](public/bookstore/ASSETS.md)・[駅](public/station/ASSETS.md)）を同梱しています。

確認コマンド：`npm test`、`npm run build`、`node scripts/deployment-smoke.mjs`。
