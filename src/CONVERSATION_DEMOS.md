# 2.5次元の人物と会話する

成人確認後に場所を選ぶと、田中さん、佐藤さん、山本さんのいずれかが登場し、行動選択を経て同じ匿名セッションで会話・終了・振り返りを行う。人物ごとのローカル台本を進める別画面はない。

実Geminiは1回の返答で text（セリフ）と expression（neutral / confused / cautious / relieved）を返す。サーバーが両方を検証して、同じ assistant メッセージに保存する。表情のための追加のモデル呼び出しはない。表情は架空の人物を演じるための指定で、練習者の採点や本人の感情の判定には使わない。画像の読込失敗、生成失敗、利用上限でも、架空の成功応答に置き換えない。

画面は最後に確定したメッセージのセリフと表情を同時に表示する。待機中にも前の返答を保持する。練習者が終了すると、同じセッションから振り返る。音声はセリフのみを読み上げる。サーバーをdemoモードにすれば、同じ画面・同じAPIで無料の定型応答を試せる。

起動時はタイトルと「うまく話すより、相手の声を聴く。」、スタートボタンを表示します。開始後は既存の説明・成人確認・場面選択へ進みます。会話と読み上げは現在の共通APIの実装を維持しています。


## 場所と人物のランダムな組み合わせ

場面選択は人物ではなく場所（スーパー・書店・駅）を選びます。選んだ時点で田中さん・佐藤さん・山本さんのうち1人を等確率で抽選し、行動選択画面に表示します。振り返り後は「同じ相手でもう一度」と「同じ場所で人物を再抽選」を選べます。再抽選では同じ人が続くこともあります。

`shared/scene-characters.ts` に人物ID・初期セリフ・行動選択の組み合わせを定義しています。背景は場所、人物の表情画像と読み上げの声は抽選された人に対応します。新たな画像生成はありません。

会話開始APIは省略可能な `characterId`（tanaka / sato / yamamoto）を受け付け、Sessionに保存します。以後の返答・振り返り・読み上げは保存済みの人物を使用し、クライアントから途中変更はできません。旧クライアントが指定を省略した場合は従来の人物対応を維持します。

`server/scene-cast.ts` に場所と人物を組み合わせた固定事実とデモ返答を保持します。3人の性格・希望は維持し、探し物や目的は現在の場所に合わせます。Gemini呼び出しの追加はなく、既存の1回の応答生成へ人物と場所を渡します。課金・認証・Firebase設定は変更していません。

9組み合わせのデモAPI会話、表情、再送、終了、振り返り、声の対応をテストしています。PC・スマホ相当のヘッドレスEdgeでも全9通りの操作と画像表示を確認しました。実機端末と実Geminiでの9組み合わせの応答は別途必要です。確認手順と範囲は `docs/browser-verification.md` を参照してください。

## 組み合わせに合う案内と再挑戦

開始前に人物ごとの練習目標を表示します。会話画面の「この場面の目的と終え方」では、選んだ行動と、9通りの人物・場所に合った終了案内を確認できます。田中さんは本人が選べる手伝い、佐藤さんは自分で確かめる意思、山本さんは短い問いや指差しを手がかりにすることを中心にし、探し物や帰宅の成功を終了条件にしません。従来3場面の説明・初期セリフ・行動IDは維持しています。

「同じ相手でもう一度」は終了したセッションの人物IDを使い、同じ場所と人物で行動選択へ戻ります。「同じ場所で人物を再抽選」は3人から等確率で選び直します。どちらも以前の会話を解放し、行動・入力・振り返りをリセットします。会話を開始すると新しいセッションを作り、前の履歴は引き継ぎません。場所一覧の元データから設定を組み立て直すため、再抽選で前の人物の選択肢が残ることはありません。

定型応答モードでは、入力を変えても同じ人物・場所の返答は同じ順序です。この制限を再挑戦ボタンの近くにも明示しています。
